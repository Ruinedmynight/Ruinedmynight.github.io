关于

你好，我是 M。一个相信简洁力量的写作者兼开发者。 这个博客是我在代码、设计、文学与生活上的思考记录——一切皆在黑白之间。

这个博客始于一个个人项目——互联网上的一处安静角落，没有社交媒体的喧嚣。 在这里，我探索真正在意的事，记录学到的东西，练习写作这门手艺。

不写作的时候，我在读书、拍黑白照片，或者做开源项目。 极简主义对我有着持久的吸引力——干净的代码、简洁的设计、诚实的文字。

这个博客用纯 HTML 和 CSS 构建，部署在 GitHub Pages 上。 它有意地保持简单——没有框架，没有追踪。只有页面上的文字，本该如此。

如果你想联系我，可以在 GitHub 或 Twitter 上找到我。
